SCT_DS_4

Traffic Accident Pattern and Hotspot Analysis

Objective

Analyze traffic accident data to identify patterns related to road conditions, weather conditions, and time of day. The project also aims to identify accident hotspots and contributing factors.

Dataset

Traffic Accident Dataset

Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

Data Cleaning

- Removed duplicate records.
- Handled missing values.
- Converted date and time columns into appropriate formats.

Analysis Performed

1. Accident distribution by weather conditions.
2. Accident distribution by time of day.
3. Analysis of road conditions and traffic signals.
4. Identification of accident hotspots.
5. Exploration of factors contributing to accidents.

Visualizations

- Weather Condition Analysis
- Time-of-Day Accident Analysis
- Road Condition Analysis
- Accident Hotspot Analysis

Key Findings

- Accident frequency varied under different weather conditions.
- Certain hours of the day recorded a higher number of accidents.
- Specific locations were identified as accident hotspots.
- Road and traffic conditions influenced accident occurrence.

Conclusion

This project helped in understanding the factors contributing to traffic accidents and demonstrated how data analysis can be used to identify patterns and improve road safety.
